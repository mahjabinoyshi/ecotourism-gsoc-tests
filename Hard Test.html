Hard Task

When I first approached this task, I assumed I would need a predictive model. But looking at the data, I realised we are not actually predicting future weather—only using historical patterns.I still used a Poisson model to estimate how expected sightings vary with weather and time, and then ranked the most favourable conditions.

Because the response variable is a count (number of sightings per hour), a Poisson model is a natural starting point. I briefly checked the mean–variance relationship to see if this assumption was reasonable.

The variance–mean ratio for Finch counts is about 0.67, and the dispersion statistic is below 1, so a Poisson model is appropriate. The IRRs show very small effects for temperature, rain, wind, and hour, with slightly stronger positive effects for dew point (humidity) and month of year.

The residuals vs fitted plot shows a roughly random scatter around zero without strong patterns, supporting that the Poisson model fits the Finch count data reasonably well.

Function: predict_top_sightings

predict_top_sightings <- function(occurrence, n_top = 5) {

  weather <- ecotourism::weather   # use built-in weather data

  joined <- occurrence |>
    dplyr::left_join(
      weather |>
        dplyr::select(ws_id, date, temp, prcp, wind_speed, dewp),
      by = c("ws_id", "date")
    ) |>
    dplyr::mutate(month = lubridate::month(date))

  hourly <- joined |>
    dplyr::filter(
      !is.na(hour),
      !is.na(temp), !is.na(prcp),
      !is.na(wind_speed), !is.na(dewp)
    ) |>
    dplyr::group_by(date, hour) |>
    dplyr::summarise(
      n_sightings = dplyr::n(),
      temp        = mean(temp,       na.rm = TRUE),
      prcp        = mean(prcp,       na.rm = TRUE),
      wind_speed  = mean(wind_speed, na.rm = TRUE),
      dewp        = mean(dewp,       na.rm = TRUE),
      month       = dplyr::first(month),
      .groups     = "drop"
    )

  model <- glm(
    n_sightings ~ temp + prcp + wind_speed + dewp + month + hour,
    family = poisson,  # or quasipoisson
    data   = hourly
  )

  hourly$predicted <- predict(model, type = "response")

  hourly |>
    dplyr::arrange(dplyr::desc(predicted)) |>
    dplyr::mutate(
      rank       = dplyr::row_number(),
      weekday    = weekdays(date),
      month_name = lubridate::month(date, label = TRUE, abbr = FALSE)
    ) |>
    dplyr::select(
      rank, month_name, weekday, hour, n_sightings,
      mean_temp = temp, mean_prcp = prcp,
      mean_wind = wind_speed, mean_dewp = dewp,
      predicted
    ) |>
    dplyr::slice_head(n = n_top)
}

The predict_top_sightings() function takes any occurrence and matching weather dataset, fits a Poisson model to hourly counts, and returns the top five date–hour combinations with the highest predicted sightings. Applied to the Gouldian Finch data, it suggests warm, humid mornings and afternoons in October and December, with about two birds expected in those hours.That said, most of the weather variables had very small effects, suggesting that short-term conditions like rain or temperature do not strongly influence sightings. I found this a bit unexpected, as I initially thought those factors would play a bigger role.
